## Aturan Keras

- **JANGAN** menulis kode sebelum membaca seluruh file di atas.
- **JANGAN** mengubah struktur yang sudah ada tanpa membaca konteks terlebih dahulu.
- Ikuti pola arsitektur Flutter yang sudah ditetapkan: Material Design, widget-based.
- Gunakan `const` constructor sedapat mungkin untuk performa.
- Jaga konsistensi tema dengan `ThemeData` dari `MaterialApp`.
- Gunakan `Navigator 2.0` / `go_router` untuk routing (sesuai keputusan arsitektur).
- Semua komunikasi HTTP melalui satu `ApiClient`/`Dio` instance terpusat.
- Simpan token JWT dengan `flutter_secure_storage`.
- JANGAN gunakan `dynamic` type — selalu gunakan model class yang ketat.
- Untuk perubahan widget yang digunakan di banyak tempat, cari dan update SEMUA pengguna.
